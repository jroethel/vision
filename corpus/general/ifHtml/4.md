### Preparing the Output

When the application is run, a document in the following format is generated:

      Content-Type: text/html

      &ltHTML>
      &ltHEAD>
      &ltTITLE> title based on inputs goes here </TITLE>
      </HEAD>
      &ltBODY>
      &ltH2> standard title goes here </H2>&ltHR>

          output from ApplicationWS formatted with HTML tags

      </BODY></HTML>

An appropriate Html header and footer is created to surround the output from the application. The application itself is executed within a [*FormatTools Html evaluate:* block](#format) so that any display tags are generated for Html.
