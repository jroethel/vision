**\[ \] <a href="Program.htm#block" id="block">Characters</a>**       Square brackets define a Block, a program representing a deferred sequence of actions.

**\| [Character](Program/2.md)**       Veritcal bars define the start and end of the named portion of a block.

------------------------------------------------------------------------

**" [Character](../classes/clString.md)**       Double quotes define the start and end of strings.

------------------------------------------------------------------------

**' [Character](Lang/6.md)**       Single quotes define the start and end of selectors.
