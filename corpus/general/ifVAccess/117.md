#### Description:

> A method that adds a date to a list of dates used to specify the time axis in time by entity or item queries.  The date string you supply must be a suitable recipient for Vision's *asDate* message.
>
> There are three ways to specify the time axis of an extract workspace:
>
> 1.  using a list of dates built using this method,
> 2.  using a comma separated list of dates specified using either the *[DateListString](#property%20ExtractWS::DateListString)* property or *[SetDateListTo](#method%20ExtractWS::SetDateListTo)* method,
> 3.  using a Vision expression specified using the *[DateListExpression](#property%20ExtractWS::DateListExpression)* property or *[SetDateListExpressionTo](#method%20ExtractWS::SetDateListExpressionTo)* method.
>
> Only one of these three alteratives can be used at a time.  The value of the *[DateListType](#property%20ExtractWS::DateListType)* property tells you which one is being used.
