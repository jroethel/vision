#### Description:

> A boolean property whose value indicates whether *[DoubleNaN](#property%20FormatSettings::DoubleNaN)* is set by this *FormatSettings* object.  This property is partially writeable.  Setting this property to *False* instructs this *FormatSettings* object to discard its local *DoubleNaN* value and begin inheriting *DoubleNaN* from its *[ParentSettings](#property%20FormatSettings::ParentSettings)* object.  It is not possible to explicitly set this property to *True*; set *DoubleNaN* instead.
