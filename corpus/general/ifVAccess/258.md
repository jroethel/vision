### Enumerated Type ExtractListType

A collection of constants that indicate how an *[ExtractWS](#class%20ExtractWS)* entity, date, or item list is defined.  The following table summarizes the possibilities:  
 

|  |  |
|----|----|
| ExtractListType_Unspecified | The entity, date, or item list is undefined. |
| ExtractListType_Array | The entity, date, or item list is defined by a series of calls to *[AddEntity](#method%20ExtractWS::AddEntity)*, *[AddDate](#method%20ExtractWS::AddDate)*, or *[AddItem](#method%20ExtractWS::AddItem)*, as appropriate. |
| ExtractListType_String | The entity, date, or item list is defined using a string of comma-separated values. |
| ExtractListType_Expression | The entity, date, or item list is defined dynamically using a Vision expresion. |
