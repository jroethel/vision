#### Description:

> A function that returns the elements of a *DatumArray* as an array of long integers.  Elements not representable as long integers are returned as the *[LongNaN](#property%20FormatSettings::LongNaN)* value of this *DatumArray*'s *[FormatSettings](#property%20DatumArray::FormatSettings)* object.
