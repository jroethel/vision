#### Description:

> A boolean property whose value indicates whether *[LongNaN](#property%20FormatSettings::LongNaN)* is set by this *FormatSettings* object.  This property is partially writeable.  Setting this property to *False* instructs this *FormatSettings* object to discard its local *LongNaN* value and begin inheriting *LongNaN* from its *[ParentSettings](#property%20FormatSettings::ParentSettings)* object.  It is not possible to explicitly set this property to *True*; set *LongNaN* instead.
