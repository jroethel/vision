#### Description:

> A read-only property whose value is the kind of entity list held in this extract workspace.  Three kinds of entity list are possible:
>
> 1.  an entity list built one entity at a time using a sequence of calls to the *[AddEntity](#method%20ExtractWS::AddEntity)* method,
> 2.  an entity list specified as a comma separated list of entity names (*[EntityListString](#property%20ExtractWS::EntityListString)*),
> 3.  an entity list dynamically derived using a Vision expression (*[EntityListExpression](#property%20ExtractWS::EntityListExpression)*).
