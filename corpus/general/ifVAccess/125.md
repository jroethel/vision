#### Description:

> Methods that add an item to the list of items used to specify the item axis in item by entity or time queries.  The item string is a Vision expression augmented by the extra item specification syntax described [here](../tkInterface/6.md).
>
> An item can be added to the item list with an explicit data type using the *AddTypedItem* method. The values of items added with an explicit data type will be converted to that data type if possible.  If the conversion cannot be performed, the value will be returned as *NA*.  Four item types are supported:
>
> 1.  return the value as a double (*[ItemType_Real](#ItemType_Real)*).
> 2.  return the value as an integer (*[ItemType_Integer](#ItemType_Integer)*).
> 3.  return the value as a string (*[ItemType_String](#ItemType_String)*).
> 4.  return the value using the most specific type possible (*[ItemType_Unspecified](#ItemType_Unspecified)*).
>
> The *AddItem* method adds untyped items to the list.  *AddItem* is equivalent to calling the *AddTypedItem* method with an item type of *ItemType_Unspecified*.
