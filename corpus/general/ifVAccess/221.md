#### Description:

> A boolean property and associated, alternative update methods that controls whether a description of the single entity, date, or item for which this extract workspace was run will be included in the first cell of the data array returned.  If necessary, an extra row and column will be added to the data array to accommodate this descriptive cell.  An extra row is not necessary if [column labels](#property%20ExtractWS::ColumnLabelsOn) are enabled.  Similarly, an extra column is not needed if [row labels](#property%20ExtractWS::RowLabelsOn) are enabled.
