#### Description:

> A method that adds an entity to a list of entities used to specify the entity axis in entity by item or time queries.  The entity string you supply must be an alias for one of the entities of type *[EntityType](#property%20ExtractWS::EntityType)* in your database.
>
> There are three ways to specify the entity axis of an extract workspace:
>
> 1.  using a list of entities built using this method,
> 2.  using a comma separated list of entities specified using either the *[EntityListString](#property%20ExtractWS::EntityListString)* property or *[SetEntityListTo](#method%20ExtractWS::SetEntityListTo)* method,
> 3.  using a Vision expression specified using the *[EntityListExpression](#property%20ExtractWS::EntityListExpression)* property or *[SetEntityListExpressionTo](#method%20ExtractWS::SetEntityListExpressionTo)* method.
>
> Only one of these three alteratives can be used at a time.  The value of the *[EntityListType](#property%20ExtractWS::EntityListType)* property tells you which one is being used.
