## [General Application Classes](../appClasses.md)

All Vision installations include a basic hierarchy of classes defined for organizing application classes. These abstract classes include:

- Entity
- DataRecord
- LinkRecord
- Bridge
- DataFeed
- DBEntity

Most applications will interact with the database via **Entity** instances. The other classes are used to store data or manage navigations from an entity to other parts of the database. General application classes are described in more detail in the document [*Core Application Classes*](../appClasses.md).

The classes [**Classification**](../../classes/clClassify.md), [**Currency**](../../classes/clCurrency.md) and [**Universe**](../../classes/clUniverse.md) are **Entity** subclasses that are useful in a wide range of applications. These classes are included as a standard component of all Vision databases. {% include doc-footer.htm copydates="1998" %}
