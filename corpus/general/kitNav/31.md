### Show Time Series Summary *{for instance}*

The **Show Time Series Summary Report** displays a summary of each time series defined for the supplied instance. The name, number of points in the time series, first date, and last date are displayed for each data item defined as a **TimeSeriesProperty** or defined to return a **TimeSeries** object. A final column indicates if the value can be updated via a [**DataFeed**](../../classes/clDataFeed.md) subclass.

If you are running the [dynamic version](#dynamic) of the Navigator, the time series name is displayed as a link to the **Show History For Time Series** report.
