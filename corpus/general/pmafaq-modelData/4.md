#### Using *Excel* to load model data

1.  

2.  Create the **DataRecord**, **ModelData**

    1.  
    2.  Select *Create DataRecord* from *VUpload* menu
    3.  Enter *ModelData* as the new *DataRecord* type
    4.  Select *DataRecord* from the *From* List Box
    5.  Select *Company* from the *Link To Entity...* list box
    6.  Enter *modelData* in the *access via:* text box.
    7.  Select *Time Series* to indicate that the model data varies over time.
    8.  Select OK

    The feed *ModelDataFeed* has been created, which is found in the *Entity Extender* feed category.

3.  Creating Properties for **ModelData**.
    1.  

    2.  In this example, you are defining the properties *model1*, *model2*, and *model3* for *ModelData*. Set up the spreadsheet to look like the following. Note that the feed name is in the top left of the range.

                    PropertySetup

              classId         Property      tsflag    datatype
              ModelData       model1        N         Number
              ModelData       model2        N         Number
              ModelData       model3        N         Number

        Note that if you want to explicitly limit the type of value to integer or non integer numbers, use the *dataType* of Integer or Double.

    3.  Select the entire range, including the feed name.

4.  Creating **ModelRecord** Instances For **Companies** Over Time
    1.  

    2.  Assuming that you have already loaded the *CompanyMaster*, set up the spreadsheet to look like the following example:

              id      date    model1  model2  model3
              ibm     9710    4.9     4.7     4.6
              ibm     9711    4.3     4.8     4.2
              ibm     9712    4.3     4.2     4.9
              gm      9710    8.4     8.5     8.9
              gm      9711    7.9     8.1     8.5
              gm      9712    8.3     8.5     8.3

    3.  Select the range.

    4.  Select *Upload Data* from the *VUpload* menu.

    5.  Select the category *EntityExtender* and the feed name *ModelDataFeed*.

    6.  Select the Range button.

5.  Access the Data
    1.  set up the spreadsheet to look like the following example:

                      modelData model1        modelData model2
              ibm
              gm

    2.  Select the range.

    3.  Select *Set Defaults* from the *Vision* menu.

    4.  Enter *Company* as the *EntityType*.

    5.  Select *Get Entity By Item Data* from the *Vision* menu.

        The output will look similar to the following example:

                      modelData model1        modelData model2
              ibm     4.3                     4.2
              gm      8.3                     8.5

        Your Extraction is complete.
