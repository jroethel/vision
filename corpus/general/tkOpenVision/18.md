### A Text File Reader

The sample is an implementation of the *asFileContents* method using The Open Vision Tool Kit:

- String defineMethod: [ | asFileContents |
          !file <- "file:" concat: ^self. asOpenVisionChannel;
          !result <- file getString;
          file close;
          result
      ];
