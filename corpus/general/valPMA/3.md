## Headstart Applications and Analyst Tools

The **Portfolio Management Application Layer** includes a starter suite of web-based applications. These applications are accessed with a web browser via an organization's intranet. The Headstart applications are described in the document, [*Portfolio Management Application: Headstart Application*](../pmaApps.md).

In addition, analysts can interact with Vision using Excel Add-ins designed to extract data from Vision and temporarily define and modify data that is used in conjunction with browser applications. These analyst tools are described in the document, [*Portfolio Management Application: Analyst Tools*](../pmaAnalyst.md).
