## Uploading Data

Standardized interfaces for loading data from external sources are provided as part of this Application Layer. An [Excel interface is available](../pmaAnalyst.md) for making temporary modifications to the database. These changes will be reflected in an analyst's private versions of browser reports, but will not be saved permanently. Tools for committing permanent changes to the database [are also provided](../pmaDBA/3.md).

The pre-defined data feeds are described in the document, [*Portfolio Management Application: Feeds*](../pmaFeeds.md).
