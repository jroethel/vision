## Class Descriptors

The class [*Schema ClassDescriptor*](../tkSchema.md) is used to maintain information about the classes in your Vision database. Each instance of *Schema ClassDescriptor* corresponds to a specific class. Messages defined for this class enable you to record information pertaining to class hierarchy, naming conventions, and descriptions. The *classDescriptor* message is defined for each class to return the instance of the *Schema ClassDescriptor* class used to store descriptive information about the class.
