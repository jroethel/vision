Name of a parameter in a keyword message followed by the : character.

------------------------------------------------------------------------

[**Keyword Message**](../Lang/4.md)       Message with one or more parameters composed of one more keywords, one preceding each parameter.

------------------------------------------------------------------------

<a href="clList.htm" id="list"><strong>List</strong></a>       Subclass of Collection containing one or more objects that are accessed either by position or as a set.

------------------------------------------------------------------------

[**Literal**](../Lang/7.md)       Number, string, block, or magic word. A literal must be the first object in an expression.

------------------------------------------------------------------------

[**Magic Word**](../Execution/2.md)       One of a set of messages to the literal *^* ("Root").

------------------------------------------------------------------------

[**Message**](../Lang/2.md)       Request for an object to carry out one of its operations.

------------------------------------------------------------------------

[**Message Descriptor**](../Messages/3.md)       Maintains information about a message in the database.

------------------------------------------------------------------------

[**Method**](../Fund/4.md)       Actual program used to implement a procedural message.

------------------------------------------------------------------------

<a href="clNA.htm" id="na"><strong>NA</strong></a>       Object representing a value that is not available.

------------------------------------------------------------------------

<a href="Lang.htm#names" id="name"><strong>Name</strong></a>       String used to name an object or a message.

------------------------------------------------------------------------

[**Navigation**](../Lang/7.md)       Process of using messages to get from one object to another.

------------------------------------------------------------------------

[**Number**](../../classes/clNumber.md)       Class whose instances represent numerical values and superclass of the *Integer*, *Double*, and *Float* classes.

------------------------------------------------------------------------

[**Object**](../Fund/2.md)       Basic unit of information representation.

------------------------------------------------------------------------

**Offset** [(see DateOffset )](#offset)

------------------------------------------------------------------------

<a href="Lang.htm#parameter" id="parameter"><strong>Parameter</strong></a>       Expression providing additional information for keyword and binary messages.

------------------------------------------------------------------------

[**Precedence Order**](../Syntax/2.md)       Unambiguous rules for ordering the execution of a Vision expression.

------------------------------------------------------------------------

[**Primitive**](../Messages/2.md)       Built-in message that cannot be viewed or modified by the user.

------------------------------------------------------------------------

[**Program**](../Program.md)       One or more expressions that function together as a unit.

------------------------------------------------------------------------

[**Property**](../Fund/2.md)       Attribute of an object.

------------------------------------------------------------------------

***Read-Eval-Print* Error** [(see Fatal Error )](#fatal)

------------------------------------------------------------------------

[**Recipient**](../Lang.md)       Object to which a message is being sent.

------------------------------------------------------------------------

[**Resolving the Message**](../Execution/3.md)       Search that is performed to determine the version of the message to use.

------------------------------------------------------------------------

[**Schema**](../tkSchema.md)       ToolKit used to manage information about the classes and messages in the Vision database.

------------------------------------------------------------------------

**Selector** [(see Name )](#name)

------------------------------------------------------------------------

[**Selector Not Found**](../Error/3.md)       Error resulting from requesting an undefined message.

------------------------------------------------------------------------

[**Shadow Instance**](../Classes/7.md)       Psuedo-instance used as a surrogate for a deleted instance.

------------------------------------------------------------------------

[**Specialization**](../Fund/2.md)       Creation of a new class.

------------------------------------------------------------------------

[**Statement**](../Program/2.md)       Single expression in a program.

------------------------------------------------------------------------

[**String**](../../classes/clString.md)       Class whose instances represent sequences of one or more characters.

------------------------------------------------------------------------

[**Subclass**](../Fund/2.md)       Class that inherits properties and methods from another class.

------------------------------------------------------------------------

[**Superclass**](../Fund/2.md)       Class from which properties and messages are inherited.

------------------------------------------------------------------------

[**Syntax Error**](../Error/2.md)       Error resulting from incorrectly formulated expressions.

------------------------------------------------------------------------

[**Temporary Work Space**](../Running/6.md)       Global environment for a session not started with an explicit object space.

------------------------------------------------------------------------

<a href="clTS.htm" id="ts"><strong>TimeSeries</strong></a>       Subclass of Collection containing one or more objects that are accessed either by date or as a set.

------------------------------------------------------------------------

[**Time Varying Property**](../Fund/4.md)       Attribute of an object that can vary over time.

------------------------------------------------------------------------

[**Top Level Object Space**](../Running/6.md)       Global environment for the session.

------------------------------------------------------------------------

[**TRUE**](../../classes/clBoolean.md)       Subclass of Boolean representing *TRUE* values.

------------------------------------------------------------------------

[**Unary Message**](../Lang/3.md)       Message without arguments.

------------------------------------------------------------------------

**Undefined** [(see NA )](#na)

------------------------------------------------------------------------
