## Restarting Master Listeners

When the database administrator has loaded new data and is ready to make it available to web users, the *master listeners* should be restarted.

<img src="starting4.gif" data-border="1" width="210" height="243" alt="Listener menu" />

Select the *Restart Master Listeners* choice from this menu. For more information on listeners, see the section [Controlling the Web Reporter](../pmaDBA/7.md).
