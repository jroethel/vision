## Using Data in Excel

You can also use the Vision data in Excel. Start a new Excel and [connect to vision](../pmaAnalyst.md). You are now ready to extract and/or upload data.

To extract holdings for portfolio *102*, select the following range:

<img src="starting6.gif" data-border="1" width="474" height="44" alt="portfolio extraction" />

Select *Get Entity By Item Data* from the *Vision* menu.

<img src="starting7.gif" data-border="1" width="319" height="67" alt="portfolio extraction results" />

The information you supplied via the *SecurityMaster*, *PortfolioMaster*, and *HoldingsFeed* upload is displayed.

For more samples of using data in Excel see [Sample Usage](../pmaAnalyst/4.md). {% include doc-footer.htm copydates="1999" %}
