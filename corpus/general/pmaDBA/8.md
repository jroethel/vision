<span id="masterlisteners"></span> To start or restart the master listeners, click on the *Vision DBA* menu and select the *Restart Master Listeners* choice. You will need to execute this option to start the listeners initially. These listeners will maintain a constant view of the database. By default, the browser applications will not see any database updates that have occurred since the master listeners were started. You will normally want to restart the master listeners after you have updated a collection of [data feed files](#data) and/or [Vision scripts](#scripts).

Your System Administrator for the Vision Server machine can arrange to automatically start the listeners each time the server is rebooted by adding the script *restartMasterListeners.cmd* located in the *localvision/adminScripts* directory on your server machine to the appropriate startup files.

More information about private listeners [is available](../pmaAnalyst/10.md).
