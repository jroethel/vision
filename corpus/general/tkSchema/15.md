### Default Values

The property *defaultValue* is used to store a default value for a *MessageImplementationDescriptor*. It is only meaningful to store default values for messages that are properties. You can set this value using the *setDefaultValueTo:* message. You can clear this value using the *clearDefaultValue* message.

When a property is defined for a class using the *defineFixedProperty:* or *define:* message, the initial value of the property is [*NA*](../../classes/clNA.md) for all instances of the class and for any new instance when it is created. The expression:

        class defineFixedProperty: 'name' withDefault: object

or

        class define: 'name' withDefault: object

runs the *defineFixedProperty:* or *define:* message and sets the default value in the associated message implementation descriptor to the supplied object. All existing instances are initialized to have this value. In addition, this property will be set to this default value as part of the execution of the [*createInstance*](../Classes/6.md) method.
