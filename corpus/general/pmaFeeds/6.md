## Reject Files

A reject file is generated when a data feed record is not processed for any reason. The reject file is created in the working directory with the same file name as the data feed appended by *.rejects*. The first line of this file is the field order list used to process the feed followed by the records that were not processed by the feed. Comments at the end of the record indicate a rejection reason where possible. Once the reject reason has been resolved the reject file can be used as the data feed. The [configuration file](#config) option *rejectFileName* can be used to customize the location and name of the reject file.
