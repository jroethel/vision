## Pre-defined Feed Summary

A number of data feeds have been pre-defined to support the Portfolio Management Application. These feeds are summarized below and are described in detail in individual fact sheets.

**Master Feeds**

These feeds are used to create new entity instances and refresh key properties in entity instances:

- [*AggAccountMaster*](../../feeds/pma-AggAccountMaster.md) creates and refreshes **AggAccount** instances.
- [*AnalystMaster*](../../feeds/pma-AnalystMaster.md) creates and refreshes **Analyst** instances.
- [*AssetCatMaster*](../../feeds/pma-AssetCatMaster.md) creates and refreshes **AssetCat** instances.
- [*CompanyMaster*](../../feeds/pma-CompanyMaster.md) creates and refreshes **Company** instances.
- [*CompositeAccountMaster*](../../feeds/pma-CompositeAccountMaster.md) creates and refreshes **CompositeAccount** instances.
- [*CountryMaster*](../../feeds/pma-CountryMaster.md) creates and refreshes **Country** instances.
- [*CurrencyMaster*](../../feeds/pma-CurrencyMaster.md) creates and refreshes **Currency** instances.
- [*IdSourceMaster*](../../feeds/pma-IdSourceMaster.md) creates and refreshes **IdSource** instances.
- [*IndexAccountMaster*](../../feeds/pma-IndexAccountMaster.md) creates and refreshes **IndexAccount** instances.
- [*IndustryMaster*](../../feeds/pma-IndustryMaster.md) creates and refreshes **Industry** instances.
- [*PortfolioMaster*](../../feeds/pma-PortfolioMaster.md) creates and refreshes **Portfolio** instances.
- [*SectorMaster*](../../feeds/pma-SectorMaster.md) creates and refreshes **Sector** instances.
- [*SecurityMaster*](../../feeds/pma-SecurityMaster.md) creates and refreshes **Security** instances.
- [*SecurityTypeMaster*](../../feeds/pma-SecurityTypeMaster.md) creates and refreshes **SecurityType** instances.
- [*UniverseMaster*](../../feeds/pma-UniverseMaster.md) creates and refreshes **Universe** instances.

**Entity Extender Feeds**

These feeds are used to update sets of data used to supplement an existing entity and usually populate **DataRecord** classes such as **PriceRecord** and **DivRecord**.

- [*AnalystEst*](../../feeds/pma-AnalystEst.md) updates earnings estimate data supplied by an analyst for **Company** instances.
- [*DivFeed*](../../feeds/pma-DivFeed.md) updates dividend data for **Security** instances.
- [*EconFeed*](../../feeds/pma-EconFeed.md) updates economic data for **Country** instances.
- [*ExchangeRateFeed*](../../feeds/pma-ExchangeRateFeed.md) updates exchange rate data for **Currency** instances.
- [*FundamentalA*](../../feeds/pma-FundamentalA.md) updates annual fundamental data for **Company** instances.
- [*FundamentalM*](../../feeds/pma-FundamentalM.md) updates monthly fundamental data for **Company** instances.
- [*FundamentalQ*](../../feeds/pma-FundamentalQ.md) updates quarterly fundamental data for **Company** instances.
- [*IndexAccountBuilder*](../../feeds/pma-IndexAccountBuilder.md) updates data associated with rule-based creation of **IndexAccount** holdings.
- [*PriceFeed*](../../feeds/pma-PriceFeed.md) updates pricing data for **Security** instances.
- [*SplitsFeed*](../../feeds/pma-SplitsFeed.md) updates stock split data for **Security** instances.

**Transaction Feeds**

These feeds are used to create, cross reference, and generate summary statistics for classes associated with two or more entities such as **Holding**.

- [*HoldingsFeed*](../../feeds/pma-HoldingsFeed.md) creates **Holding** instances and cross references the holdings over time by **Portfolio** and **Security**.

**Alias Feeds**

These feeds are used to establish multiple aliases for specific entity instances.

- [*SecurityAliases*](../../feeds/pma-SecurityAliases.md) establishes aliases for **Security** instances.

**XRef Feeds**

These feeds are used to load alternative identifiers.

- [*SecurityXRef*](../../feeds/pma-SecurityXRef.md) is used to load alternative identifiers for **Security** instances.

**Membership Feeds**

These feeds are used to update and cross reference one-to-many relationships such as *company-to-industry* over time.

- [*CompanyToAnalyst*](../../feeds/pma-CompanyToAnalyst.md) updates the *company-analyst* relationship over time.
- [*CompanyToCountry*](../../feeds/pma-CompanyToCountry.md) updates the *company-country* relationship.
- [*CompanyToIndustry*](../../feeds/pma-CompanyToIndustry.md) updates the *company-industry* relationship over time.
- [*CompositeAccountMembers*](../../feeds/pma-CompositeAccountMembers.md) updates the composition of **CompositeAccounts** over time.
- [*IndustryToSector*](../../feeds/pma-IndustryToSector.md) updates the *industry-sector* relationship.
- [*PortfolioAggregates*](../../feeds/pma-PortfolioAggregates.md) updates the **Portfolio** members of **AggAccounts** over time.
- [*UniverseMembers*](../../feeds/pma-UniverseMembers.md) creates and names lists of related entities over time.

**RangeGroup Feeds**

These feeds are used to define and update numeric ranges and categorize entities into the appropriate range group.

- [*McapGroups*](../../feeds/pma-McapGroups.md) assigns **Security** instances to a group based on market capitalization.
- [*PbGroups*](../../feeds/pma-PbGroups.md) assigns **Security** instances to a group based on price-to-book ratios.
- [*PeGroups*](../../feeds/pma-PeGroups.md) assigns **Security** instances to a group based on price-to-earnings ratios.
