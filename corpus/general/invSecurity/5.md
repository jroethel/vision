## Other Security Messages

The following section summarizes additional messages defined for the Security class and indicates where they are described in further detail, if appropriate:

**Basic Security Data**

\*\_eps

unadjusted earning per share value

eps

split/currency adjusted eps

\*\_sharesOut

unadjusted shares outstanding

sharesOut

split adjusted shares outstanding

\_price

unadjusted price

marketCap

currency adjusted market capitalization

pe

price-earnings ratio

issuer

same as *company*

\* type

instance of SecurityType class

unitCalc

unit adjustment for mkt value calcs (default 1.0)

\* Indicates a property value that can be changed directly

The *\_eps*, *\_sharesOut*, and pricing data are usually updated as part of an external pricing feed. These values are all stored over time and are updated using the *asOf:put:* message. Split and currency adjustment issues are described more fully in the [Investment Issues](../invIssues.md) document. The *type* and *unitCalc* properties are maintained as part of the external pricing update or as part of an internal security *refresh* feed. These values can be changed using the standard assignment operation. For example, the expression:

        Named Security GM :_sharesOut asOf: 9311 put: 1234000 ;

assigns the value 1234000 as GM's shares outstanding value as of November 1993 and the expression:

        Named Security GM :unitCalc <- 1.0 ; 

assigns the values 1 to the *unitCalc* property.
