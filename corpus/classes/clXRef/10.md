## The ToolKit Class

Subclasses of this class are used to organize packages of classes and messages offered as a unit to perform a set of related functions. Built-in ToolKits include [*The OpenVision ToolKit*](../../general/tkOpenVision.md), [*The Schema ToolKit*](../../general/tkSchema.md), and [*The UserInterface ToolKit*](../../general/tkInterface.md).
