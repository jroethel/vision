## The ToolKit Class

Subclasses of this class are used to organize packages of classes and messages offered as a unit to perform a set of related functions. Built-in ToolKits include [*The OpenVision ToolKit*](tkOpenVision.htm), [*The Schema ToolKit*](tkSchema.htm), and [*The UserInterface ToolKit*](tkInterface.htm).
