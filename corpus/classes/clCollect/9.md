## Inter-Collection Messages

A number of messages have been defined to perform operations **between** two lists. The messages can be sent to an instance of any *Collection* subclass and return a *List* object unless otherwise noted.

**Message**

**Definition**

**Sample**

[*+*](../../messages/mList/__26b172.md)

Add *parameter* to *recipient* (List or TimeSeries only); *parameter* can be a scalar number or a list of numbers

5 sequence + 5 sequence

[*-*](../../messages/mList/__336d5e.md)

Subtract *parameter* from *recipient* (List or TimeSeries only); *parameter* can be a scalar number or a list of numbers

5 sequence - 3

[*\**](../../messages/mList/__3389da.md)

Multiply *recipient* by *parameter* (List or TimeSeries only); *parameter* can be a scalar number or a list of numbers

5 sequence \* 5 sequence

[*/*](../../messages/mList/__6666cd.md)

Divide *recipient* by *parameter* (List or TimeSeries only); *parameter* can be a scalar number or a list of numbers

5 sequence / 2

<a href="mList.htm#isEquivalentTo:" data-<i="">isEquivalentTo:</a>

Returns *Boolean* indicating if *recipient* and *parameter* have equivalent content

5 sequence isEquivalentTo: 1,2,3,4,5 .

<a href="mList.htm#union:" data-<i="">union:</a>

Returns *List* of elements in either or both the *recipient* and *parameter*

5 sequence union: 3 sequence .

<a href="mList.htm#union:using:" data-<i="">union:using:</a>

Returns *List* of elements in either or both the *recipient* and *parameter1* using block supplied as *parameter2* to modify the elements before comparing for equality

list1 union: list2 using: \[ asSelf \] .

<a href="mList.htm#intersect:" data-<i="">intersect:</a>

Returns *List* of elements in both the *recipient* and *parameter*

5 sequence intersect: 3 sequence .

<a href="mList.htm#intersect:using:" data-<i="">intersect:using:</a>

Returns *List* of elements in both the *recipient* and *parameter1* using block supplied as *parameter2* to modify the elements before comparing for equality

list1 intersect: list2 using: \[ asSelf \] .

<a href="mList.htm#exclude:" data-<i="">exclude:</a>

Returns *List* of elements in *recipient* that are not in *parameter*

5 sequence exclude: 3 sequence .

<a href="mList.htm#exclude:using:" data-<i="">exclude:using:</a>

Returns *List* of elements in *recipient* that are not in *parameter1* using block supplied as *parameter2* to modify the elements before comparing for equality

list1 exclude: list2 using: \[ asSelf \] .

<a href="mList.htm#difference:" data-<i="">difference:</a>

Returns a *List* of 2 elements: the first contains the *List* of elements that are in *recipient* and not in *parameter*; the second contains the *List* of elements that are in *parameter* and not in *recipient*

list1 difference: list2 .
