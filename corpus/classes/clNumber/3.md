<span id="comparison"></span> The following messages perform the basic **relational** operations. These messages can be sent to an instance of any *Number* subclass and return an instance of the [*Boolean*](../clBoolean.md) class. Parameters are an instance of any *Number* subclass except where explicitly noted.

**Message**

**Definition**

**Sample**

*=*

Is *recipient* equal to *parameter*?

2 = 2.0

*==*

Is *recipient* [identical](../../general/Navigate/6.md) to *parameter*?

2 == 2.0

*!=*

Is *recipient* not equal to *parameter*?

2 != 2.0

*!==*

Is recpient not identical to *parameter*?

2 !== 2.0

*\<*

Is recpient less than *parameter*?

1 \< 2.0

*\<=*

Is recpient less than or equal to *parameter*?

1 \<= 2.0

*\>*

Is recpient greater than *parameter*?

1 \> 2.0

*\>=*

Is recpient greater than or equal to *parameter*?

1 \>= 2.0

[*between:and:*](../../messages/mNumber/between_and_.md)

Is recpient value between two *parameter* values?

5 between: 3 and: 7 .

[*inRange:*](../../messages/mNumber/inRange_.md)

Is recpient value in the range implied by the *parameter*, a list of two elements representing the start and end of the range inclusively?

5 inRange: 3,7 .

[*inSet:*](../../messages/mNumber/inSet_.md)

Is recpient equal to one of the values in the *parameter*, a list containing one or more elements?

5.0 inSet: 1,3,5,7,9 .

[*notBetween:and:*](../../messages/mNumber/notBetween_and_.md)

Is recpient value not between two *parameter* values?

5 notBetween: 3 and: 7 .

[*within:percentOf:*](../../messages/mNumber/within_percentOf_.md)

Is recpient value within *parameter1* percent of *parameter2*?

100 within: 10 percentOf: 105 .

The following messages perform other **standard computations**. These messages can be sent to an instance of any *Number* subclass.

**Message**

**Definition**

**Sample**

[*absoluteValue*](../../messages/mNumber/absoluteValue.md)

Absolute value of *recipient*

-2 absoluteValue

[*asAPowerOf:*](../../messages/mNumber/asAPowerOf_.md)

Raise *parameter* to the *recipient* power

3 asAPowerOf: 2 .

[*exp*](../../messages/mNumber/exp.md)

Raise the constant *e* (~ 2.7183) to the *recipient* power

3 exp

[*log*](../../messages/mNumber/log.md)

Compute natural log of *recipient*

3 log

[*log:*](../../messages/mNumber/log_.md)

Compute log of *recipient* using numeric *parameter* as base

3 log: 10 .

[*max:*](../../messages/mNumber/max_.md)

Returns the larger of *recipient* and *parameter* value

3 max: 4 .

[*min:*](../../messages/mNumber/min_.md)

Returns the smaller of *recipient* and *parameter* value

3 min: 4 .

[*negated*](../../messages/mNumber/negated.md)

Multiplies *recipient* by -1

3 negated

[*pctChangeTo:*](../../messages/mNumber/pctChangeTo_.md)

Computes percentage change between *recipient* and *parameter* relative to *parameter*

3 pctChangeTo: 2 .

[*round*](../../messages/mNumber/round.md)

Round *recipient* to nearest integer

3.3 round

[*round:*](../../messages/mNumber/round_.md)

Round *recipient* to *parameter* number of decimals places

3.333 round: 2 .

[*sign*](../../messages/mNumber/sign.md)

Returns -1, 0, or 1 based on sign of *recipient*

3 sign

[*sqrt*](../../messages/mNumber/sqrt.md)

Square root of *recipient*

3 sqrt

The following messages perform other **standard computations**. These messages are only defined for *Integers*.

**Message**

**Definition**

**Sample**

[*adjustedMod:*](../../messages/mNumber/adjustedMod_.md)

*Recipient modulo parameter*, returning an integer between 1 and *parameter*

10 adjustedMod: 5 .

[*mod:*](../../messages/mNumber/mod_.md)

*Recipient modulo parameter*, returning an integer between 0 and *parameter - 1*

10 mod: 5 .

[*numberOfDigits*](../../messages/mNumber/numberOfDigits.md)

Integer number of digits in *recipient*

3 numberOfDigits

The following messages perform the basic **trigonometric** operations. These messages can be sent to an instance of any *Number* subclass and return an instance of the class *Double*.

**Message**

**Sample**

*cosine*, *sine*, *tangent*

0 cosine

*arcCosine*, *arcSine*, *arcTangent*

1 arcCosine

*hyperbolicCosine*, *hyperbolicSine*, *hyperbolicTangent*

0 hyperbolicCosine
