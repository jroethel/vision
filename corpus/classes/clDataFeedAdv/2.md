## Bridges and EstimateBridges

The subclasses of the **Bridge** class are used to manage the protocol for connecting an entity to one more **DataRecord** instances. It is useful when there are complex relationships that need to be managed and you do not want to overburden the entity class with all the required information. An instance of a **Bridge** subclass is normally referenced via the entity instance with which it is associated. The **BatchFeedManager** class supplies an [interface for creating bridge subclasses](admBatch.htm#Bridges).
