This upload will create **CountryMaster** and **IndustryMaster** as subclasses of **MasterFeed** (if they do not already exist) and link them to the entity classes **Country** and **Industry**.

Note that if the **Country** and/or **Industry** class does not exist, the corresponding **MasterFeed** subclass will **not** be created. Use the [**ClassSetup**](15.md) class to create new **Entity** subclasses.
