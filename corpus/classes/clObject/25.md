## General Access and Update Messages

Several messages have been defined at the *Object* class to support **general access and update** for all objects:

**Message**

**Definition**

[*getPotentialChoicesForString:*](../../messages/mObject/getPotentialChoicesForString_.md)

Returns *List* of objects in *recipient's* class that could be associated with *parameter*

[*validateInputString:*](../../messages/mObject/validateInputString_.md)

Returns object in *recipient's* class associated with the supplied *parameter*

<a href="mObject.htm#extract:forDateRange:" data-<i="">extract:forDateRange:</a>

Evaluates *parameter1* block for *recipient* for each date in *parameter2*, returning the result as a *TimeSeries*

<a href="mObject.htm#setProperty:to:" data-<i="">setProperty:to:</a>

Updates *parameter1* with the value of *parameter2* in *recipient*

<a href="mObject.htm#updateTS:with:" data-<i="">updateTS:with:</a>

Updates time series indicated by *parameter1* with the value of *parameter2* in *recipient*
