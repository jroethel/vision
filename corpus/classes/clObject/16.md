<span id="instancesAccess"></span> The following messages are used to [**access the instances**](Classes.htm#access) in the recipient's class:

**Message**

**Definition**

[*instanceList*](../../messages/mObject/instanceList.md)

Returns *List* of all instances in *recipient's* class

[*masterList*](../../messages/mObject/masterList.md)

Returns *List* of all non-default instances in *recipient's* class

[*activeList*](../../messages/mObject/activeList.md)

Returns *List* of all non-default instances in *recipient's* class that are not flagged for deletion

Many messages have been defined at the *Object* class to support a variety of database administration fucntions. [Detailed information](admDBA.htm) is available.
