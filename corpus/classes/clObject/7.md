<span id="descriptive"></span> The message [*displayInfo*](../../messages/mObject/displayInfo.md) is defined to display an object's class name and value followed by a carriage return. Some classes, such as [Entity](../clEntity/3.md) redefine this message to display additional information. For example, the expression:

      Named Currency US displayInfo ; 

displays the *code* and *name* of the object representing the US currency.

The message [*profile*](../../messages/mObject/profile.md) is defined to display a descriptive report for an object. Some classes, such as [Entity](../clEntity/3.md) redefine this message to display additional information. For example, the expression:

      Named Currency US profile ; 

displays a descriptive report about the object representing the US currency.
