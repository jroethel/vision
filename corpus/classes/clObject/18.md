<span id="messageCreate"></span> The following messages are used to [**create and delete messages**](../../general/Fund/4.md) and are normally sent to the default instance of the class:

**Message**

**Definition**

[*defineFixedProperty:*](../../messages/mObject/defineFixedProperty-c63889.md)

Define fixed property named by *parameter* for *recipient's* class

[*defineFixedProperty:withDefault:*](../../messages/mObject/defineFixedProperty-withDefault.md)

Define fixed property named by *parameter1* for *recipient's* class and set default value to *parameter2*

[*define:*](../../messages/mObject/define-0ed76c.md)

Define time varying property named by *parameter* for *recipient's* class

[*define:withDefault:*](../../messages/mObject/define-withDefault.md)

Define time varying property named by *parameter1* for *recipient's* class and set default value to *parameter2*

[*define:toBe:*](../../messages/mObject/define-toBe-a52a58.md)

Define class constant named by *parameter1* that returns value of *parameter2*

[*defineMethod:*](../../messages/mObject/defineMethod-71096f.md)

Define method for *recipient's* class using block provided as *parameter*

[*deleteMessage:*](../../messages/mObject/deleteMessage.md)

Delete message named by *parameter* from *recipient's* class
