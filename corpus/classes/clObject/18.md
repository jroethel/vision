<span id="messageCreate"></span> The following messages are used to [**create and delete messages**](Fund.htm#message) and are normally sent to the default instance of the class:

**Message**

**Definition**

[*defineFixedProperty:*](../../messages/mObject/defineFixedProperty_.md)

Define fixed property named by *parameter* for *recipient's* class

[*defineFixedProperty:withDefault:*](../../messages/mObject/defineFixedProperty_withDefault_.md)

Define fixed property named by *parameter1* for *recipient's* class and set default value to *parameter2*

[*define:*](../../messages/mObject/define_.md)

Define time varying property named by *parameter* for *recipient's* class

[*define:withDefault:*](../../messages/mObject/define_withDefault_.md)

Define time varying property named by *parameter1* for *recipient's* class and set default value to *parameter2*

[*define:toBe:*](../../messages/mObject/define_toBe_.md)

Define class constant named by *parameter1* that returns value of *parameter2*

[*defineMethod:*](../../messages/mObject/defineMethod_.md)

Define method for *recipient's* class using block provided as *parameter*

[*deleteMessage:*](../../messages/mObject/deleteMessage_.md)

Delete message named by *parameter* from *recipient's* class
