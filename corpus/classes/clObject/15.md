<span id="instanceCreation"></span> The following messages are used to [**create new instances**](../../general/Classes/6.md) of a class:

**Message**

**Definition**

[*createInstance*](../../messages/mObject/createInstance.md)

Creates and returns a new instance in *recipient's* class

[*createInstance:*](../../messages/mObject/createInstance_.md)

Creates and returns a new instance in *recipient's* class, using *parameter* string to name the new instance

[*initializeGlobalInstanceProperties*](../../messages/mObject/initializeGlobalInstanceProperties.md)

Sets initial values in new instance

[*basicNew*](../../messages/mObject/basicNew.md)

Primitive method to create and return new instance of *recipient's* class, without running any special initialization steps

[*clusterNew*](../../messages/mObject/clusterNew.md)

Primitive method to create and return new instance of *recipient's* class, without running any special initialization steps used with some built-in classes to ensure that instances are [clustered](../../general/Classes/9.md)
