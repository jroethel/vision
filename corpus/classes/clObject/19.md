<span id="messageAccess"></span> The following messages are used to [**access and the display**](../../general/Messages/4.md) the messages defined for the recipient's class:

**Message**

**Definition**

[*getMessage:*](../../messages/mObject/getMessage_.md)

Retrieve the *MessageImplementationDescriptor* in *recipient's* class for the message named by *parameter*

[*getMessages*](../../messages/mObject/getMessages.md)

Return *List* of messages in *recipient's* class

[*showMessages*](../../messages/mObject/showMessages.md)

Display messages in *recipient's* class

[*getMessagesX*](../../messages/mObject/getMessagesX.md)

Return *List* of messages in *recipient's* class and its superclasses

[*showMessagesX*](../../messages/mObject/showMessagesX.md)

Display messages in *recipient's* class and its superclasses

[*getMessagesDefining:*](../../messages/mObject/getMessagesDefining_.md)

Return *List* of messages in *recipient's* class hierarchy that define the message specified by *parameter*

[*showMessagesDefining:*](../../messages/mObject/showMessagesDefining_.md)

Display messages in *recipient's* class hierarchy that define the message specified by *parameter*

[*getMessageNamesContaining:*](../../messages/mObject/getMessageNamesContaining_.md)

Return *List* of messages in *recipient's* class hierarchy with names that contain the substring specified by *parameter*

[*showMessageNamesContaining:*](../../messages/mObject/showMessageNamesContaining_.md)

Display messages in *recipient's* class hierarchy with names that contain the substring specified by *parameter*

[*getMessagesUsing:*](../../messages/mObject/getMessagesUsing_.md)

Return *List* of methods in *recipient's* class hierarchy that use the substring specified by *parameter*

[*showMessagesUsing:*](../../messages/mObject/showMessagesUsing_.md)

Display names of methods in *recipient's* class hierarchy that use the substring specified by *parameter*

[*showMethodsUsing:*](../../messages/mObject/showMethodsUsing_.md)

Display implementations of methods in *recipient's* class hierarchy that use the substring specified by *parameter*

[*getMessagesInInheritancePath*](../../messages/mObject/getMessagesInInheritancePath.md)

Return *List* of messages in *recipient's* class hierarchy

[*showProperties*](../../messages/mObject/showProperties.md)

Display messages defined as properties in *recipient's* class

[*selectorList*](../../messages/mObject/selectorList.md)

Primitive method to return list of strings representing messages defined for *recipient*
