## Frequently Used Messages

Messages defined at *Object* are available to all objects in the database. The following tables summarize the most frequently used messages. They are described in more detail in later sections.

The following messages are used to **access** and **display** basic information about a specific object:

**Message**

**Definition**

[*code*](#basic)

*String* representing *recipient's* user-defined id

[*creationDate*](#basic)

*Date* of *recipient's* creation

[*whatAmI*](#basic)

*String* identifying *recipient's* class

[*print*](#display)

Display *recipient* using default format for its class

[*print:*](#display)

Display *recipient* using supplied format for

[*printNL*](#display)

Display *recipient* using default format followed by a new line

[*printNL:*](#display)

Display *recipient* using supplied format followed by a new line

[*displayInfo*](#descriptive)

Display a line of summary information about *recipient*

[*profile*](#descriptive)

Display a descriptive report about *recipient*

The following messages are used to **evaluate** programs, sending all statements to the recipient object:

**Message**

**Definition**

[*do: \[\]*](#do:)

Evaluate *parameter* in the context of *recipient* and return the *recipient*

[*send: \[\]*](#do:)

Evaluate *parameter* in the context of *recipient* and return the result of evaluating *parameter*

[*extendBy: \[\]*](#extendBy:)

Evaluate *parameter* in the context of *recipient* and return a specialization of *recipient* that includes variables defined in *parameter*

The following additional messages are frequently used:

**Message**

**Definition**

[*=*](#compare)

Is *recipient* equal to *parameter*?

[*!=*](#compare)

Is *recipient* not equal to *parameter*?

[*asList*](../clList/2.md)

Convert *recipient* to a *List* containing one element

[*asSelf*](#extensions)

Return *recipient* stripped of any extensions

[*asString*](Output.htm#convert)

Convert *recipient* to a *String*

[*isNA*](#isMessages)

Is *recipient* an instance of the *Undefined* class?

[*isntNA*](#isMessages)

Is *recipient* not an instance of the *Undefined* class?

[*else: \[ \]*](../clNA/4.md)

If *recipient* is *NA* evaluate *parameter*; otherwise, return *recipient*

[*elseIf:\[\] then: \[\]*](../clNA/4.md)

If *recipient* is *NA* evaluate *parameter1*; if it is *TRUE*, evaluate *parameter2* otherwise, return *recipient*

[*ifTrue:\[\]ifFalse:\[\]else:\[\]*](../clNA/4.md)

If *recipient* is *TRUE* evaluate *parameter1*; if *recipient* is *FALSE* evaluate *parameter2*; otherwise, evaluate *parameter3*

The following messages are used to perform class-level operations and are normally sent to the default instance of a class:

**Message**

**Definition**

[*createSubclass:*](#classCreation)

Create a subclass of the *recipient*

[*instanceList*](#instancesAccess)

*List* of instances in *recipient's* class

[*createInstance:*](#instanceCreation)

Create instance in *recipient's* class

[*defineFixedProperty:*](#messageCreate)

Define fixed property in *recipient's* class

[*define:*](#messageCreate)

Define time series property in *recipient's* class

[*define:toBe:*](#messageCreate)

Define class constant in *recipient's* class

[*defineMethod:*](#messageCreate)

Define method in *recipient's* class

[*getMessage:*](#messageAccess)

Retrieve the *MessageImplementationDescriptor* in *recipient's* class for the message named by *parameter*

[*showMessages*](#messageAccess)

Display all messages defined directly for *recipient's* class

[*showMessagesX*](#messageAccess)

Display all messages defined for *recipient's* class and its superclasses

[*showInheritance*](#classAccess)

Display the *recipient's* position in the class hierarchy
