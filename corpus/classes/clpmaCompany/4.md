Messages such as *industry* and *primarySecurity* return an object of another entity class. You can therefore navigate to that object and request any of its information. For example, the expression:

      Named Company GM primarySecurity name

returns the name of GM's primary security and the expression:

      Named Company GM industry showMessages

displays the messages defined for the **Industry** class.

Company instances return instances of the classes **Country**, **Industry**, and **Sector** via the messages *country*, *industry*, and *sector*. These classes are [described below](#related).

For general descriptions of all the **Company** messages, see the document [*Vision Application Messages: Company*](mpmaCompany.htm). A number of messages have been defined to address company identification and the relationship between a company and the securities issued by it. These messages are described in more detail in the document [*Portfolio Management Application Issues*](../../general/pmaIssues/7.md).

Messages such as *securityType* and *company* return an object of another entity class. You can therefore navigate to that object and request any of its information. For example, the expression:

      Named Security GM company name

returns the name of GM's company and the expression:

         Named Security GM type showMessages

displays the messages defined for the **SecurityType** class.

Security instances return instances of the classes **SecurityType** and **AssetCategory** via the message *type* and the expression *type assetCategory* [described below](#related). Messages that access pricing and dividend information such as *price* and *dividend* interact with the **PriceRecord** and **DivRecord**, classes, also [described below](#datarec) . Messages that are used to support [split adjustment](#splits) are also described later in this document.

A number of messages are defined at **Security** to return related **Account** and **Holding** information. These messages are described in the document [*Vision Application Classes: The Account Classes*](../clpmaAccount/17.md).

For general descriptions of all the **Security** messages, see the document [*Vision Application Messages: Security*](mpmaSecurity.htm). A number of messages have been defined to address security identification and the relationship between a **Security** and its issuing company. These messages are described in more detail in the document [*Portfolio Management Application Issues*](../../general/pmaIssues/7.md).
