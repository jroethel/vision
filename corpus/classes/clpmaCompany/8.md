## Updating Company and Security Data

The **Interface** class [**ExternalFeedManager**](../clDataFeed.md) has been created to provide a uniform way to create and update any entity-related information. **DataFeed** subclasses are defined to translate one or more rows of information into the appropriate structures in your Vision database. Data can be supplied from a file, a spreadsheet, a relational database, or any other table-based source. You can also supply data directly as a string, using the tab character to delimit columns and the carriage return to delimit rows.

Several **DataFeed** classes have been defined to load data for **Company**, **Security**, and related classes:

DataFeed

Description

[CompanyMaster](../../feeds/pma-CompanyMaster.md)

creates **Company** instances and refreshes basic properties

[SecurityMaster](../../feeds/pma-SecurityMaster.md)

creates **Security** instances and refreshes basic properties

[PriceFeed](../../feeds/pma-PriceFeed.md)

updates pricing data for **Security** instances

[DivFeed](../../feeds/pma-DivFeed.md)

updates dividend data for **Security** instances

[SplitsFeed](../../feeds/pma-SplitsFeed.md)

updates stock split data for **Security** instances

[SecurityAliases](../../feeds/pma-SecurityAliases.md)

establishes aliases for **Security** instances

[CountryMaster](../../feeds/pma-CountryMaster.md)

creates **Country** instances and refreshes basic properties

[IndustryMaster](../../feeds/pma-IndustryMaster.md)

creates **Industry** instances and refreshes basic properties

[SectorMaster](../../feeds/pma-SectorMaster.md)

[SecurityTypeMaster](../../feeds/pma-SecurityTypeMaster.md)

[IndustryToSector](../../feeds/pma-IndustryToSector.md)

The [**CompanyMaster**](../../feeds/pma-CompanyMaster.md) data feed class can be used to create and refresh **Company** instances. The following tab-delimited feed could be used to create **Company** instances and refresh basic information:

      Interface ExternalFeedManager upload: "CompanyMaster" using:
    #-- make sure this is tab-delimited
      "Id          Name         fiscalYearEnd
       00036110    AAR CORP          5    
       00079410    ACC CORP          12    
       00095710    ABM INDUSTRIES    10
      " ;

The following tab-delimited string could be used to create and refresh **Security** instances:

       Interface ExternalFeedManager upload: "SecurityMaster" using:
       #-- make sure this is tab-delimited
       "entityId    name       companyId   cusip      ticker  currencyId  type
        00036110    AAR COM    00036110    00036100   AIR     USD         1
        00079410    ACC COM    00079410    00079410   ACCC    USD         1
        00095710    ABM IND    00095710    00095710   AMB     USD         1
        "  ;

The following tab-delimited string could be used to update prices:

      Interface ExternalFeedManager upload: "PriceFeed" using:
    #-- make sure this is tab-delimited
      "entityId    date        currencyId    close     volume
       12345610    19971117    USD           88.000    0.28
       12345610    19971118    USD           87.500    0.15
       12345610    19971119    USD           42.000    0.63    
       98765410    19971117    CAD           30.500    0.32    
       98765410    19971118    CAD           30.400    0.05    
       98765410    19971119    CAD           29.900    0.07    
      " ;
