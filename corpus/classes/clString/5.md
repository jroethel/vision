## Conversion Messages

Several messages have been defined to **convert** an instance of *String* to an instance of another class:

**Message**

**Definition**

**Sample**

[*asCurrency*](../../messages/mString/asCurrency.md)

Convert *recipient* to an instance of [*Currency*](../clCurrency.md)

"USD" asCurrency

[*asInteger*](../../messages/mString/asInteger.md)

Convert *recipient* to an integer

"123" asInteger

[*asNumber*](../../messages/mString/asNumber.md)

Convert *recipient* to a number

"123.45" asNumber

[*convertToNumber*](../../messages/mString/convertToNumber.md)

Remove non-numeric characters from start and end of *recipient* and any commas from remaining string and convert to a number

"123,456.78" convertToNumber

[*toList*](../../messages/mString/toList.md)

Convert *recipient* to a list of one character strings

"abcdef" toList

Several messages have been defined to convert a *String* into a Vision program. The program can be [run immediately](../../general/Input/3.md) or returned as a [*Block*](../clBlock.md) that can be evaluated at a later time.

**Message**

**Definition**

**Sample**

[*evaluate*](../../messages/mString/evaluate.md)

Interpret the *recipient* as Vision code and run it

"whatAmI" evaluate

[*evaluateIn:*](../../messages/mString/evaluateIn_.md)

Interpret the *recipient* as Vision code and run it in the context of *parameter*

"whatAmI" evaluateIn: Currency .

[*asBlock*](../../messages/mString/asBlock.md)

Convert *recipient* to a block

"whatAmI" asBlock value

[*asBlockIn:*](../../messages/mString/asBlockIn_.md)

Convert *recipient* to a block in the context of *parameter*

"whatAmI" asBlockIn: Named Currency USD . value
