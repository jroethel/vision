## Formatting Messages

Many messages defined for the class *String* allow you to reformat the strings in a variety of ways. These messages all return a *String* object. Note that the original string is never modified; a new string object is returned.

The following messages provide different ways to **pad** strings:

**Message**

**Definition**

**Sample**

[*center:*](../../messages/mString/center.md)

Center *recipient* over *parameter* columns

"xyz" center: 80 .

[*fill:*](../../messages/mString/fill.md)

Repeat characters in *recipient* until string of *parameter* length is formed

"xyz" fill: 20 .

[*pad:*](../../messages/mString/pad.md)

Pad *recipient* with blanks until string of *parameter* length is formed

"xyz" pad: 20 .

The following messages provide different ways to **strip characters** out of strings:

**Message**

**Definition**

**Sample**

[*stripChar:*](../../messages/mString/stripChar.md)

Remove the characters in *parameter* from *recipient*

"abacadae" stripChar: "ad" .

[*stripBoundingBlanks*](../../messages/mString/stripBoundingBlanks.md)

Remove blanks from start and end of *recipient*

" xyz " stripBoundingBlanks

[*stripLeadingBlanks*](../../messages/mString/stripLeadingBlanks.md)

Remove blanks from start of *recipient*

" xyz " stripLeadingBlanks

[*stripTrailingBlanks*](../../messages/mString/stripTrailingBlanks.md)

Remove blanks from end of *recipient*

" xyz " stripTrailingBlanks

The following messages provide some basic **reformatting** operations:

**Message**

**Definition**

**Sample**

[*asQuotedString*](../../messages/mString/asQuotedString.md)

Returns *recipient* surrounded by quote characters

"xyz" asQuotedString

[*capitalize*](../../messages/mString/capitalize.md)

Capitalize first letter in *recipient*

"xyz" capitalize

[*lowercase*](../../messages/mString/lowercase.md)

Change first letter in *recipient* to a lower case letter

"Xyz" lowercase

[*reverse*](../../messages/mString/reverse.md)

Reverse order of characters in *recipient*

"xyz" reverse

[*toLower*](../../messages/mString/toLower.md)

Convert all letters in *recipient* to lower case

"XYZ" toLower

[*toUpper*](../../messages/mString/toUpper.md)

Convert all letters in *recipient* to upper case

"xyz" toUpper

[*at:put:*](../../messages/mString/at-put.md)

Insert string supplied as second *parameter* at position in *recipient* indicated by first *parameter*

"xyz" at: 2 put: "abc"

[*translate:to:*](../../messages/mString/translate-to.md)

Replace all occurrences of character supplied as first *parameter* with string supplied as second *parameter*

"xyz" translate: "x" to: "a" .
