## Basic String Messages

The following messages perform **basic** *String* operations. Except where noted, these messages return a *String* object. Note that the original string is never modified; a new string object is returned.

**Message**

**Definition**

**Sample**

[*count*](../../messages/mString/count.md)

Number of characters in string returned as an *Integer*

"xyz" count

[*drop:*](../../messages/mString/drop_.md)

Drop *parameter* characters from beginning or end of *recipient*

"xyz" drop: 2 .

[*take:*](../../messages/mString/take_.md)

Take *parameter* characters from beginning or end of *recipient*

"xyz" take: 2 .

[*concat:*](../../messages/mString/concat_.md)

Concatenate the *parameter* string to the *recipient*

"xyz" concat: "abc"

[*at:*](../../messages/mString/at_.md)

Return single character at position indicated by *parameter*

"xyz" at: 2 .

[*contains:*](../../messages/mString/contains_.md)

Return boolean indicating if *recipient* contains *parameter*

"whatAmI" contains: "what" .
