## Additional TimeSeries Messages

You can redefine *Collection* messages and define new messages directly for the *TimeSeries* class. You can define any number of new methods and constants. You cannot define and update properties for *TimeSeries* objects.

The following messages are used to **update** *TimeSeries* objects:

**Message**

**Definition**

**Sample**

[*asOf:put:*](../../messages/mTS/asOf-put.md)

Update *recipient* as of date in *parameter1* with object in *parameter2*, inserting a new date if necessary

ts asOf: 95 put: 10 .

[*put:*](../../messages/mTS/put.md)

Update *recipient* as of ^date with object in *parameter*, inserting a new date if necessary

ts put: 10 .

[*asOf:assign:*](../../messages/mTS/asOf-assign.md)

Change *recipient* as of date in *parameter1* with object in *parameter2*

ts asOf: 95 assign: 10 .

[*\<-*](../../messages/mTS/op-bec4a7.md)

Change *recipient* as of ^date with object in *parameter*

ts \<- 10

[*updateWith:*](../../messages/mTS/updateWith.md)

Update *recipient* as of ^date if *parameter* is different from current value

ts updateWith: 10 .

[*delete:*](../../messages/mTS/delete.md)

Delete *parameter* date from *recipient*

ts delete: 95 asDate

[*deleteAllPoints*](../../messages/mTS/deleteAllPoints.md)

Delete all points from *recipient*

ts deleteAllPoints

[*deleteColumnForDate:*](../../messages/mTS/deleteColumnForDate.md)

Delete all points for all instances in *recipient's* cluster as of *parameter*

ts deleteColumnForDate: 95 asDate .

*deleteColumn*

Delete all points for all instances in *recipient's* cluster as of ^date

ts deleteColumn

**Definition**

[*lead:*](../../messages/mTS/lead.md)

The following messages are used to **extract** specific subsets from *TimeSeries* objects:

**Message**

**Definition**

**Sample**

[*from:to:*](../../messages/mTS/from-to.md)

Return new time series with date-values from *recipient* corresponding the dates between *parameters*

ts from: 94 to: 95 .

[*from:*](../../messages/mTS/from.md)

Return new time series with date-values from *recipient* corresponding the dates on or after *parameter*

ts from: 95 .

[*to:*](../../messages/mTS/to.md)

Return new time series with date-values from *recipient* corresponding the dates on or before *parameter*

ts to: 95 .

[*extractForDateRange:*](../../messages/mTS/extractForDateRange.md)

Return new time series with date-values from *recipient* for each date in *parameter*

ts extractForDateRange: drange .

[*extractExactValuesForDateRange:*](../../messages/mTS/extractExactValuesForDateRange.md)

Return new time series with date-values from *recipient* for each date in *parameter*; if value does not exist on exact date, return default value for that date

ts extractExactValuesForDateRange: drange .
