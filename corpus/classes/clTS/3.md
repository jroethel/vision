Since the *TimeSeries* class is a subclass of *Collection*, messages such as *do:*, *send:*, *select:*, *groupedBy:*, *sortUp:*, *decileDown:*, and *extendBy:* are available to *TimeSeries* objects as well. Within the block supplied as the parameter, all messages are sent to each element in the recipient time series. When the recipient is a *TimeSeries* object, the [magic word *^date*](../../general/Execution/15.md) is rebound to the specific date being analyzed. For example:

      Named Currency USD :tsProperty
      do: [ ^date print: 15 ;          #- display date of element
            printNL ;                  #- print value of element
          ] ;

displays:

      1/31/1995   10.10
      2/28/1995   12.30
      3/31/1995    9.70

The *toList* message can be used to convert a *TimeSeries* into a standard *List* object. For example:

      Named Currency USD :tsProperty toList at: 1 .

returns the value *10.1* which is the first value positionally after the *TimeSeries* has been converted to a *List*. Note that once the time series has been converted to a list, the specific *^date* values are not available.
