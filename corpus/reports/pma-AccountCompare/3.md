## Inputs:

| Position | Form Id     | Description                                   |
|----------|-------------|-----------------------------------------------|
| 1        | id          | Id of the base account                        |
| 2        | ids         | Ids of one or more accounts to compare        |
| 3        | group       | Grouping criteria (from menu)                 |
| -        | groupEntry  | Override for group value (from input)         |
| 4        | -           | Specific group to display                     |
| -        | details     | Indicates if all details should be displayed  |
