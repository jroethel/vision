## Summary:

- The *FundamentalA* feed is used to create and update **FundamentalDataA** data record instances for companies. A separate **FundamentalDataA** record is created for each fiscal year-end date for which data is available for a company. The data is accessed via the time series property *funDataA* defined for the **Company** class.

  This feed can include data for any number of companies for any number of dates and can be used to initialize new dates, set initial values for properties and/or change existing values.

  This class is described in the [*Portfolio Management Application Supplemental Classes*](pmaSupp.htm#Fundamental) document.
