## Summary:

- The *SecurityMaster* feed is used to create and refresh basic information for **Security** instances. This feed can also be used to create **Company** instances for cases where the security represents the primary issue for a company. A number of [related feeds](5.md) have been defined to update additional security information such as prices, dividends, and splits.
