<span id="print:"></span>**print:**

> **Synopsis:**
>
> > Date print: anInteger
>
> **Description:**
>
> > Prints the recipient date using the supplied format. If the width is less than 8 characters, the format is mm/yy padded with spaces at the right. If the width is 8 characters, the format is mm/dd/yy. If the width is 9 characters, the format is mm/dd/yy\_. Otherwise, the format is mm/dd/yyyy padded with spaces at the right.
>
