# Vision Superexpert Knowledge Base Implementation Plan

> For executors: tasks use checkbox syntax; execute in dependency order; a task is done when its
> acceptance check passes. No specific tooling, harness, or skills are assumed.

**Goal:** Turn `docs/original/` into a committed markdown corpus that the installed qmd search retrieves and traverses, wrapped as a repo-committed Claude Code skill summoned by `just -g vision`, with a human-gated loop that grows verified learnings across sessions.

**Approach:**
Convert the frozen HTML docs to a clean markdown corpus with pandoc, shredding the message files per-message at their existing `<A name>` anchors and stamping each unit with a provenance pointer, then rewrite all cross-references to resolve within the corpus.
Access and traverse the corpus through the already-installed qmd hybrid search and the preserved links, with no new retrieval, graph, or memory infrastructure built.
Wrap the corpus as one `vision-expert` skill committed in the repo, summon it with one new global launcher recipe, and grow it with a human-gated review queue that lives outside the indexed corpus so nothing unreviewed is ever retrievable.

**Tech stack:** Python 3 (stdlib only) + pandoc 3.5 for ingest, qmd 2.5.3 for retrieval, `just` 1.58.0 launcher, Claude Code skill for packaging.

**Source brief:** `docs/briefs/2026-09-21.vision-superexpert-kb-brief.md`

## Global constraints

- Never edit or move `docs/original/`; it is the frozen dated snapshot and every unit derives from it.
- Every derived unit carries a `provenance:` frontmatter pointer to its frozen source file and anchor.
- No derived unit exceeds 2000 tokens, enforced at shred time as an 8000-character heuristic ceiling (`len(text) // 4`).
- One retrieval backbone only: qmd's local index. No new vector store, graph database, memory framework, or MCP server; those are parked.
- The qmd index is machine-local cache (`~/.cache/qmd/`); the derived corpus under `corpus/` is committed, and any project-local `.qmd/` is gitignored.
- The corpus and the review queue live at the repo root (`corpus/`, `learnings-queue/`), deliberately outside `docs/`, because `docs/` is a live GitHub Pages Jekyll site (`docs/_config.yml` sets `defaults: layout: single` with no `exclude:`) and units placed under it would be swept into the published site and could break its build.
- Nothing unreviewed is retrievable: the review queue lives at `learnings-queue/`, outside `corpus/`, so it is never in the qmd collection.
- Code and the ivr testkit are ground truth; a retrieved schema or feed claim is unverified-as-of-retrieval and must be checked against live source or ivr at use time before any feed or schema commit.
- No new pip or npm dependency; ingest uses the Python standard library plus the already-installed `pandoc`, `qmd`, and `claude` CLIs.
- Editing `~/.config/just/justfile` (outside this repo, in personal config) is a human checkpoint: the recipe is staged in the repo and the user applies it.

## Dependency graph

```
Task 1 (ingest harness)
   |
   +--> Task 2 (feed + report family)   \
   +--> Task 3 (class + message family) /  (2 and 3 parallel, disjoint families and output dirs)
            |
            +--> Task 4 (full corpus build + integration)   [runs all families in ONE pass,
                     |                                        resolves cross-family links, commits
                     |                                        the complete corpus]
                     +--> Task 5 (index + retrieval)   \
                     +--> Task 6 (traversal)           /  (5 and 6 parallel, disjoint files)
                              |
                              +--> Task 7 (summon: skill + staged recipe)   [needs 5's index]
                                       |
                                       +--> Task 8 (grow: learning loop)
```

Why Task 4 exists: Tasks 2 and 3 each build only their own family (`--only`), so a link from a class unit to a message unit cannot resolve until every family is registered in one `run.py` pass.
Task 4 is that single integrated pass; it owns the complete `corpus/` and is the only task that rewrites cross-family links, which removes any parallel write to the corpus by later tasks.

Waves: [Task 1] -> [Task 2, Task 3] -> [Task 4] -> [Task 5, Task 6] -> [Task 7] -> [Task 8].

## Human checkpoints

- After Task 7: the user applies the staged `vision` recipe to `~/.config/just/justfile`, runs `just -g vision`, and confirms the session boots in the repo with the `vision-expert` skill active. This edits personal config outside the repo, so it is the user's action, not an executor's.
- After Task 8 (the brief's one `[judgment]` criterion): the summoned expert completes one real co-primary task using only the knowledge base (author or correct a feed field mapping, or design an entity subclass with the right superclass and property kinds), and a human judges that the result checks out against live source or the ivr testkit.

## Parked (known limitations, not built here)

- No retract or supersede-a-learning path: `promote_learning.py` only adds, and `supersedes` points only at a frozen-source anchor, so a promoted learning that later becomes wrong stays retrievable until manually deleted. Building a retract/tombstone path is deferred to the grow-loop's next iteration.

**Interfaces:**
- Produces `common.Unit`, a dataclass with fields:
  - `source: str` frozen-source path relative to repo root, e.g. `docs/original/mObject.htm`
  - `anchor: str | None` the source `<A name>` value this unit came from, or `None` for whole-file units
  - `unit_type: str` one of `general`, `feed`, `report`, `status`, `class`, `message`, `learning`
  - `title: str` human title for the unit
  - `extra: dict` family-specific frontmatter (e.g. `{"class": "clObject"}` or `{"fields": [...]}`)
  - `body_html: str` the HTML fragment for this unit, pre-conversion
  - `out_path: str` corpus-relative output path, e.g. `messages/mObject/createSubclass.md`
- Produces `common.BUDGET_CHARS = 8000` and `common.token_estimate(text: str) -> int` returning `len(text) // 4`.
- Produces `common.slug(anchor: str) -> str`: a filesystem-safe stem. ASCII `[A-Za-z0-9_]` pass through; any other character (a message like `send:`, `->`, `!=`, `,`) is replaced by `_` and, when the result is empty or collides, suffixed with a short hex of the original so distinct anchors never share a filename. The real anchor is always preserved verbatim in the unit's `title` and in the anchor registry.
- Produces `common.render_frontmatter(unit: Unit) -> str`: emits YAML frontmatter with keys in this order: `provenance` (value `"{source}#{anchor}"` when anchor set, else `"{source}"`), `unit_type`, `title`, `ingested` (the build date, an as-of stamp so a reader sees the snapshot age next to any answer), then any `extra` keys. Every scalar value is emitted with `json.dumps(value)` (JSON is a YAML subset, so this quotes and escapes safely) rather than raw text, because real message titles include `!=`, `,`, `>`, `send:`, and `createSubclass:at:`, which as bare YAML scalars are parse errors or silently corrupt to an empty string. List and dict values (e.g. `extra["fields"]`) are emitted as JSON too.
- Produces the anchor registry: `common.register_anchor(source_htm: str, anchor: str, out_path: str) -> None` and `common.resolve_anchor(source_htm: str, anchor: str | None) -> str | None` returning the corpus-relative out_path for a `<file.htm>#<anchor>` (or the file's whole-file unit when anchor is `None`).
- Produces `common.rewrite_links(markdown: str, current_out_path: str) -> str`: rewrites every `](<file>.htm#<anchor>)` and `](<file>.htm)` link whose target is in the registry into a corpus-relative link from `current_out_path`; a link whose target is not registered is left as-is and counted so the traversal check can report it.
- Produces `common.pandoc_html_to_md(html_fragment: str) -> str`: runs `pandoc -f html -t gfm --wrap=none` over the fragment via `subprocess`, returning gfm markdown.
- Produces `common.shred_html(html: str, budget_chars: int = BUDGET_CHARS) -> list[tuple[str | None, str]]`: splits a whole-file HTML fragment into chunks each small enough that the final unit (converted markdown + frontmatter) stays at or under `budget_chars`. It splits first at section boundaries (`<h1>`-`<h4>` headings and `<a name="...">` anchors); a section still over budget is split further at safe boundaries (tag/paragraph/newline, never mid-tag) by a character window. Returns a list of `(anchor_or_None, chunk_html)` where `anchor` is the chunk's leading `<a name>` value when it began at one, else `None`. A fragment already under budget returns a single `[(None, html)]`. This is the shared shredder both `general.py` and `classes.py` use so large whole-file docs are never dropped for exceeding budget. Because the ceiling is measured on the converted markdown, leave headroom for pandoc expansion and the frontmatter (target the body chunk at roughly `budget_chars - 1500` raw HTML chars, then verify post-conversion).
- Shred out-path convention (both families): the FIRST chunk keeps the doc's canonical path `<family>/<stem>.md` (so `<stem>.htm` links and checks naming `<stem>.md` still resolve); overflow chunks go to `<family>/<stem>/<n>.md` starting at `n=2`. Register the file-level anchor (`register_anchor(source, None, ...)`) to the first chunk's `<stem>.md`, and register each section anchor to its chunk's out_path.
- Each family module in `families/` exposes two names consumed by `run.py`:
  - `SELECTOR(path: pathlib.Path) -> bool`: true when this family claims the source file. `run.py` assigns each `docs/original/*.htm` to the first family whose `SELECTOR` returns true, so ownership is exclusive and no file is processed twice.
  - `extract(paths: list[pathlib.Path], common) -> list[common.Unit]`: parses claimed files into units and calls `common.register_anchor` for every anchor it will emit. It does not convert HTML or rewrite links; `run.py` does both centrally.
- `run.py` orchestration (two phases, so cross-family links resolve):
  1. Discover `families/*.py` (excluding `__init__`), import each, and partition `docs/original/*.htm` by `SELECTOR`. Any file no family claims goes to `general`.
  2. Phase A: call every family's `extract`, collecting all units and populating the anchor registry.
  3. Phase B: for each unit, convert `body_html` with `pandoc_html_to_md`, prepend `render_frontmatter`, run `rewrite_links`, check `token_estimate(final) <= 2000` (on failure print `BUDGET <out_path> <chars>` to stderr, do not write the file, and make the process exit nonzero at the end), and write passing units to `corpus/{out_path}`.
  4. `--only <family>` limits the run to the named family and may be repeated (`--only messages --only classes`); it is how Tasks 2 and 3 build one family before the others exist. With no `--only`, every family runs in one pass (Task 4), which is the only run that resolves cross-family links.
- `families/general.py`: `SELECTOR` returns true for any `.htm` not matching `pma_*`, `cl*`, or `m*` naming; `extract` calls `common.shred_html` on each doc. A doc under budget emits one whole-file unit (`unit_type=general`, `anchor=None`, `out_path=general/<stem>.md`). A doc over budget emits one sub-unit per chunk under the shred out-path convention (first chunk `general/<stem>.md`, overflow `general/<stem>/<n>.md`), each `unit_type=general` with `anchor` set to the chunk's section anchor when it has one. Over-budget docs are shredded, never dropped: measured against this corpus, 64 of 95 general docs and 17 of 22 class docs exceed the whole-file budget, so shredding is the common case, not the exception.

`check_corpus.py` (verbatim; this is the shared corpus invariant checker used here and re-imported by later checks):

```python
#!/usr/bin/env python3
"""Assert corpus-wide invariants over a corpus directory (or subdirectory)."""
import sys, pathlib, json

_INVALID = object()  # marks a frontmatter value that is not valid JSON/YAML-safe

def parse_frontmatter(text):
    """Values are emitted as json.dumps(...); parse them back and flag any that
    do not round-trip. A key line is 'key: <json-value>'; the key has no colon,
    so the first colon is always the separator even when the value contains ':'."""
    if not text.startswith("---\n"):
        return None, text
    end = text.find("\n---\n", 4)
    if end == -1:
        return None, text
    fm = {}
    for line in text[4:end].splitlines():
        if ":" in line:
            k, _, v = line.partition(":")
            v = v.strip()
            try:
                fm[k.strip()] = json.loads(v) if v else ""
            except json.JSONDecodeError:
                fm[k.strip()] = _INVALID
    return fm, text[end + 5:]

def check(root):
    root = pathlib.Path(root)
    units = sorted(root.rglob("*.md"))
    assert units, f"no units found under {root}"
    errors = []
    for u in units:
        text = u.read_text(encoding="utf-8")
        fm, body = parse_frontmatter(text)
        if fm is None:
            errors.append(f"{u}: no frontmatter")
            continue
        if any(v is _INVALID for v in fm.values()):
            errors.append(f"{u}: frontmatter value is not valid JSON (unescaped scalar?)")
        if not fm.get("provenance"):
            errors.append(f"{u}: missing provenance")
        if not fm.get("unit_type"):
            errors.append(f"{u}: missing unit_type")
        if len(text) // 4 > 2000:
            errors.append(f"{u}: over budget ({len(text)} chars)")
    for e in errors:
        print("FAIL", e)
    print(f"checked {len(units)} units, {len(errors)} errors")
    return 1 if errors else 0

if __name__ == "__main__":
    sys.exit(check(sys.argv[1] if len(sys.argv) > 1 else "corpus"))
```

    src_count = len(glob.glob("docs/original/pma_*.htm"))

```python
#!/usr/bin/env python3
"""Class/message family checks."""
import sys, pathlib, re, glob
sys.path.insert(0, str(pathlib.Path(__file__).parent))
from check_corpus import check

def count_anchors(htm):
    return len(re.findall(r'(?i)<a name=', pathlib.Path(htm).read_text(errors="ignore")))

def main():
    # mObject.htm has 330 <A name> anchors (verified 2026-09-21) -> 330 message units.
    src = count_anchors("docs/original/mObject.htm")
    units = list(pathlib.Path("corpus/messages/mObject").glob("*.md"))
    assert len(units) == src, f"mObject messages: {len(units)} units vs {src} anchors"

    # Corpus-wide: every real message file (all m*.htm except mXRef.htm, the differently-shredded
    # index) contributes exactly one unit per <A name> anchor. This closes the brief's
    # believed-unchecked risk that only mObject follows the anchor-per-message structure, catching a
    # systematic shred failure in any of the other 26 files mechanically instead of by chance.
    msg_src = [f for f in glob.glob("docs/original/m*.htm") if "mXRef" not in f]
    total_anchors = sum(count_anchors(f) for f in msg_src)
    total_units = sum(
        1 for p in pathlib.Path("corpus/messages").rglob("*.md") if p.parent.name != "mXRef"
    )
    assert total_units == total_anchors, \
        f"message units {total_units} != source anchors {total_anchors} across {len(msg_src)} files"

    # A colon-bearing message name shredded to a safe filename but keeps its title.
    cs = pathlib.Path("corpus/messages/mObject/createSubclass.md")
    assert cs.exists(), "mObject#createSubclass unit missing"

    # clObject class unit exists.
    assert pathlib.Path("corpus/classes/clObject.md").exists(), "clObject class unit missing"

    rc = check("corpus/messages") or check("corpus/classes")
    print(f"mObject units={len(units)} (anchors={src}); total message units={total_units}")
    return rc

if __name__ == "__main__":
    sys.exit(main())
```

**Interfaces:**

`check_traversal.py` (verbatim):

```python
#!/usr/bin/env python3
"""Deep-link resolution: a known chain resolves; every clObject link resolves except where the
frozen source itself links to a nonexistent anchor (dangling-at-source, recorded not failed)."""
import re, sys, pathlib

CORPUS = pathlib.Path("corpus")
ORIG = pathlib.Path("docs/original")

def all_links(md_path):
    return re.findall(r"\]\(([^)]+)\)", md_path.read_text(encoding="utf-8"))

def resolve_md(from_path, target):
    p = (from_path.parent / target.split("#")[0]).resolve()
    return p.exists()

def source_anchor_exists(htm, anchor):
    f = ORIG / htm
    return f.exists() and re.search(r'(?i)<a name="%s"' % re.escape(anchor),
                                    f.read_text(errors="ignore")) is not None

def main():
    start = CORPUS / "classes" / "clObject.md"
    assert start.exists(), "clObject unit missing"
    targets = all_links(start)

    # Chain: clObject -> mObject#createSubclass, rewritten to a corpus .md path that resolves.
    chain = [t for t in targets if "messages/mObject/createSubclass" in t]
    assert chain, f"clObject has no rewritten link to mObject#createSubclass:\n{targets}"
    assert resolve_md(start, chain[0]), f"chain link does not resolve: {chain[0]}"

    fixable, dangling = [], []
    for t in targets:
        base = t.split("#")[0]
        if base.endswith(".md"):
            if not resolve_md(start, t):
                fixable.append(t)  # a corpus .md link that does not resolve is always a bug
        elif base.endswith(".htm"):
            # residual (unregistered) source link: classify against the frozen source
            anchor = t.split("#", 1)[1] if "#" in t else ""
            (fixable if anchor and source_anchor_exists(base, anchor) else dangling).append(t)

    if dangling:
        print("known dangling-at-source (recorded, not a failure):")
        for d in dangling:
            print("  ", d)
    assert not fixable, f"clObject fixable unresolved links (anchor exists in source): {fixable}"

    print(f"traversal OK: chain resolves; {len(dangling)} dangling-at-source; no fixable drops")
    return 0

if __name__ == "__main__":
    sys.exit(main())
```
